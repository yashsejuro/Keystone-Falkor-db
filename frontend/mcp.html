Graph Algorithms as Agent MCP Tools

Keystone exposes its multi-hop graph algorithms as standardized Model Context Protocol (MCP) tools. LLM agents (such as Claude Desktop, Cursor, or autonomous pipelines) can autonomously call shortest-path traversals, betweenness centrality rankings, and reviewer affinities directly from FalkorDB.

💻 Claude Desktop Setup

claude_desktop_config.json

Add Keystone to your Claude Desktop config to enable graph tools in chat:

{
  "mcpServers": {
    "keystone": {
      "command": "python",
      "args": [
        "c:\\Keystone-Falkor-db\\mcp_server.py"
      ]
    }
  }
}

🖱️ Cursor IDE Setup

.cursor/mcp.json

Configure Cursor to route agent review reasoning through Keystone:

{
  "mcpServers": {
    "keystone": {
      "command": "python",
      "args": ["backend/mcp_server.py"]
    }
  }
}
