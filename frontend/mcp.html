Graph Algorithms as Agent Tools

Keystone exposes its multi-hop graph algorithms as standardized Model Context Protocol (MCP) tools. LLM agents (such as Claude Desktop, Cursor, or autonomous pipelines) can call shortest-path traversals, betweenness centrality rankings, and reviewer affinities directly from FalkorDB.

Claude Desktop Configuration

claude_desktop_config.json

Add Keystone to Claude Desktop to enable graph tools in chat: 

{
  "mcpServers": {
    "keystone": {
      "command": "python",
      "args": [
        "backend/mcp_server.py"
      ]
    }
  }
}
