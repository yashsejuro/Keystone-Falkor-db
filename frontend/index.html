How the candidate connects to touched files via graph traversals

⚡ Live OpenCypher Query for this Multi-Hop Traversal 
MATCH (pr:PullRequest {number: $pr})-[:TOUCHES]->(f:File)-[c:CO_CHANGES]->(f2:File)
MATCH (f2)<-[:TOUCHES]-(other:PullRequest)<-[:REVIEWED]-(r:Person)
WHERE r.login = $reviewer
RETURN r.login, sum(c.weight) AS affinity, count(DISTINCT f2) AS bridge_files
